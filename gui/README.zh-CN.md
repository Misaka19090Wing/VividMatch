界面从功能选择页进入，提供四种比对模式，四种同时也列在「文件」菜单里。

## 界面语言

界面为双语。英文是原文语言，因此代码里的字符串是英文，中文放在
`../i18n/vividmatch_zh_CN.qm`；该文件缺失时界面保持英文 —— 这正是选英文当原文的原因。

- 首次运行跟随操作系统的界面语言。
- 「文件 → 语言 / File → Language」提供「跟随系统」「English」「简体中文」，选择由
  `QSettings` 保存，并会提示下次启动生效。
- 各页面都实现了 `changeEvent()`，在 Qt 派发 `LanguageChange` 时重建自身文案；带数字的
  字符串（结果面板、分组标题、状态行）由保存的状态重新生成而不是重新翻译。这是尽力而为，
  并不能保证每个面板都生效，因此提示只要求重启，而不承诺即时切换。

`gui\build_gui.bat` 在构建时一并生成翻译，需要 Qt Linguist 工具里的 `lrelease`。没有时
会给出警告并产出仅英文的程序，功能仍然可用。

`LanguageManager` 会依次在可执行文件旁边（`translations/`、`i18n/`、可执行文件所在目录）
以及上一级目录查找 `.qm`，因此无论从构建目录还是便携包运行都能找到。

## 图片比对模式

选择图片比对后会打开一个页面，用户选择两张图片，运行
`../cpp/visual_fingerprint.hpp` 里的 OpenCV DCT 指纹比对。

图片可以用按钮选择，也可以从文件管理器拖拽到对应的预览面板上。

## 批量图片比对模式

批量模式支持整个文件夹、多选文件，或直接拖拽。每行显示缩略图、文件名、分辨率、类型、
大小、修改日期、路径与位深度。比对完成后，重复组按相似度排在前面；勾选策略决定每组
保留哪一张处于勾选状态（默认：分辨率最高）。选择「不取消勾选」则组内全部保持勾选。

批量列表的操作：

- 分组行为与资源管理器一致，可折叠／展开。
- 单击表头在升序 -> 降序 -> 取消排序之间循环。
- Ctrl+单击表头可追加次级及更多排序字段。
- 右键表头可显示／隐藏列；拖动表头可调整顺序。
- 回车打开选中图片，Delete 从列表移出，Ctrl+F 聚焦定位／搜索框。
- 双击打开图片；右键菜单提供复制路径、属性、打开所在文件夹、移出、删除、比对等操作。
- 右键分组行有分组菜单：展开／折叠（本组或全部）、整组勾选／取消／反选、只保留策略
  最优的一张、打开组内全部图片、打开所在文件夹、移出该组、只移出或删除组内勾选项、
  开始比对。
- 拖动列边缘可调整列宽。勾选框始终左对齐在「选中」单元格起始处，因此列被拉宽也不会
  漂到中间；该列最小可以缩到刚好放下勾选框为止；分组／子项树的缩进保持很小，左侧几乎
  不浪费空间。拉宽「缩略图」会把缩略图同步放大（各自保持宽高比），该行行高随之增加，
  缩略图不会被截断；分组标题行保持自身高度，不随缩略图变大。

## 视频比对模式

视频比对选择两段视频，在工作线程里运行
`../cpp/video_fingerprint.hpp` / `../cpp/audio_fingerprint.hpp` 的视觉、时序与音频三层，
并显示封面帧以及每段视频的分辨率／帧率／时长。指纹计算本身是并发的
（`../cpp/parallel_extract.hpp`）：音频阶段与视频解码重叠，两段视频并行解码，因此等待
时间取决于最长的那一段，而不是四个阶段之和。结果面板给出判定结论以及支撑它的数据：
采样与匹配帧数、单调链长度、覆盖率、链完整度、平均帧相似度，以及在对齐秒数上的音频
相似度。逐帧匹配阈值可调，音频层可关闭。音频层需要 `PATH` 中有 `ffmpeg` 命令行；没有
时判定退回画面与时序结果。

## 批量视频比对模式

批量视频比对支持添加文件夹、多选视频或拖拽，然后把同一个视频归为一组
（`../cpp/video_batch.hpp`），并用星号标出保留项。保留策略由下拉框选择：分辨率最高／
最低、文件最大／最小、修改日期最近／最远，或全部保留。每段视频只解码一次（线程池），
先用紧凑签名预筛，音频只为视觉上已匹配的视频提取，因此一整个长视频文件夹也能实用。

它对齐了批量图片页面的做法：「选中」勾选列、「画面」预览列、视频行与分组行都有右键
菜单、Ctrl+F 定位，以及相同的全选／反选／移出勾选项／删除勾选文件。

几个值得了解的行为：

- 视频一加入就出现在列表里。分辨率与时长在后台探测打开文件之前显示为横杠，探测会连同
  预览帧一起拿到这两项，无需先比对一次。
- 「截帧位置」数值框决定缩略图取片长百分之多少处（默认 50%，即中间，因为第一帧往往是
  标题卡或黑场淡入）。改动在点「重新截帧」后生效，而不是每敲一个键就重抓一次 —— 每次
  抓帧都要 seek 并解码。
- 缩略图随「画面」列宽缩放，行高随之增减，与批量图片页面的缩略图行为一致。
- 「开始比对」跟随勾选状态而不是列表长度：只有在勾选了至少 2 个视频时才可用，且比对
  的正是这勾选的若干个。取消全部勾选会让按钮禁用，而不是悄悄退回去比对整个列表。
- 每次比对会替换结果，但未参与比对的视频（未勾选，或比对之后才加入的）会留在「待比对」
  分组里，不会消失。

```bat

```

运行：


## 便携包

在装有 Qt 与 OpenCV 的机器上执行一次：

```bat
gui\package_gui.bat
```

结果输出到 `dist\VividMatchGui\`。Qt 的 DLL／插件与 OpenCV 运行时 DLL 都会复制到可执行
文件旁边，因此整个文件夹可以直接拷到另一台既没有 Qt 也没有 OpenCV 的 Windows x64
电脑上。直接运行 `VividMatchGui.exe`，或在仓库里用 `gui\run_gui.bat` 启动。

## 不同机器上的路径

脚本不会假定某个用户目录。设置了 `QT_ROOT`、`OPENCV_ROOT` 或 `OPENCV_BIN` 环境变量时
优先使用这些值；否则脚本会去常见安装位置查找，例如 `C:\Qt`、`D:\Qt`、
`%USERPROFILE%\Qt`、`C:\opencv`、`D:\opencv`、`%USERPROFILE%\opencv`。

`CMAKE_GENERATOR` 与 `CMAKE_GENERATOR_ARGS` 可以覆盖，以支持 Visual Studio 2022 x64
以外的工具链。

如果 `PATH` 中没有 CMake，脚本会退回使用 `python -m cmake`。

在 Visual Studio Code 中用 `Qt: Register Qt installation` 注册已安装的 Qt 根目录，然后
用 CMake Tools 配置 `gui/CMakeLists.txt`。
